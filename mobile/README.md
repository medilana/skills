# Mobile

## Plugin tersedia
- `mobile/expo-skills` (plugin `expo`) — skill resmi tim Expo: build UI Expo
  Router, data fetching, deployment, upgrade SDK (React Native/Expo).
- `mobile/appstore-review-skill` (plugin `appstore-review-skill`) — audit app
  sebelum submit ke App Store/Play Store. Support Swift, Flutter, React
  Native, Expo, KMP.

## Skill dari folder lain yang juga relevan
- `../frontend/ui-ux-pro-max-skill` — dukung stack SwiftUI, Jetpack Compose,
  React Native, Flutter untuk urusan desain/UI.
- `../qa/midscene` — E2E testing lintas Android, iOS, HarmonyOS, desktop
  (bukan hanya web). Catatan: ini SDK biasa, bukan Claude Code plugin.
